## AWS Cloud Quest: Cloud Practitioner

A hands-on, role-playing learning experience where cloud concepts are applied by building real-world solutions directly in the AWS console - not just theory, but practical experience with live AWS services.

**What I did**
Completed a series of guided cloud missions covering core AWS services including compute (EC2), storage (S3), networking (VPC), databases (RDS), and security (IAM). Each mission required configuring, deploying, and troubleshooting actual AWS infrastructure in a sandboxed environment.

**What I learned**
- Fundamental cloud computing concepts — regions, availability zones, scalability, and the shared responsibility model
- Core AWS services and when to use each one
- How to architect simple, reliable solutions using AWS best practices
- Foundational knowledge aligned with the AWS Certified Cloud Practitioner exam
