AWS SimuLearn – Security Concepts Certificate

I completed the AWS SimuLearn Security Concepts course to build a strong foundation in AWS cloud security and identity management.

In this course, I learned the basics of how access and security work in AWS, including:

- The difference between IAM users, roles, and groups, and when to use each
- How IAM policies are structured and how permissions are granted or restricted
- The AWS Shared Responsibility Model and what security tasks are handled by AWS vs. the customer
- Best practices for securing access, such as using least privilege and enabling multi-factor authentication (MFA)

This certificate reflects my growing understanding of AWS security fundamentals and my commitment to building secure and responsible cloud solutions.
